Flujo de convocatoria

La convocatoria empieza con asistencia pendiente y se bloquea progresivamente cuando se crea la alineacion, se registran resultados y se abre/cierra el postpartido.

PENDING_ATTENDANCE→ READY_FOR_LINEUP→ MATCHES_CREATED→ RESULTS_COMPLETED→ POST_MATCH_OPEN→ CLOSED

Reglas principales

PENDING_ATTENDANCEAun faltan respuestas o no se alcanza el minimo. No se debe formar alineacion.
READY_FOR_LINEUPHay suficientes jugadoras confirmadas. Se habilita Formar Alineacion.
MATCHES_CREATEDLa propuesta ya esta seleccionada y existen partidos. Se bloquean cambios de alineacion.
RESULTS_COMPLETEDTodos los partidos de la convocatoria tienen resultado guardado.
POST_MATCH_OPENLos jugadores pueden rellenar feedback postpartido.
CLOSEDConvocatoria cerrada. No se editan asistencias, alineacion ni feedback.

Flujo de partido

El listado de partidos muestra el resultado si existe y traduce el estado tecnico a una lectura operativa.

pdtJuego→ pdtPostPartido→ cerrado

Lectura visual

pdtJuegoNo hay resultado. Capitan o coach deben entrar en /matches/:id desde la pista para anotar resultado.
pdtPostPartidoYa hay resultado. Aparece feedback para jugadoras y el listado indica quien falta por responder.
cerradoResultado y postpartido completados. Desaparece accion de feedback.

Estados tecnicos BD

DRAFTPartido creado desde alineacion o manualmente, pendiente de resultado.
PLAYEDResultado guardado. Abre el ciclo de postpartido.
CLOSEDPartido cerrado para cambios posteriores.
